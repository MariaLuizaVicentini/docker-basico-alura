# Docker Básico - Alura 🐳

Repositório dedicado aos meus estudos de **Docker**, com anotações, comandos e exemplos práticos desenvolvidos durante o curso de Docker da Alura.

O objetivo é compreender os fundamentos da ferramenta, aprender a trabalhar com containers e imagens e explorar recursos que facilitam a criação e a execução de ambientes de desenvolvimento.


## 🛠️ Conceitos e ferramentas

- **Docker Engine:** gerenciamento e execução de containers.
- **Docker Images:** estrutura em camadas e criação de imagens.
- **Docker Containers:** criação, execução e gerenciamento.
- **Docker Hub:** download e distribuição de imagens.
- **Docker Volumes:** persistência de dados.
- **Bind Mounts:** compartilhamento de arquivos entre host e container.
- **Dockerfile:** definição de instruções para construção de imagens próprias.
- **Port Mapping:** comunicação entre portas do host e do container.

## 💻 Exemplos práticos

- Execução de aplicações em containers.

- Compartilhamento de diretórios utilizando volumes.
